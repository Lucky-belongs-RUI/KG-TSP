# PLM-based Knowledge Graph Topological-Semantic Path-Aware Model for Link Prediction

A knowledge graph completion (KGC) method based on pretrained language models (BERT) and path-enhanced prompting. It converts KG entities, relations, and graph structural paths into textual prompts, then uses a BERT dual-encoder for link prediction.

## Requirements

- Python >= 3.7
- CUDA GPU (recommended, ~8-16GB VRAM for training)

### Generate Path Prompt Data

Run `src/data_process/data_set.py` to generate path prompt files from graph data:

```bash
# Modify the HYPERPARAMS dict in the __main__ block of data_set.py:
#   'dataname': 'FB15k237'   # Dataset name
#   'max_hops': 2             # Maximum path hops
#   'mode': 'path'            # 'path' for entity-name paths, 'relation' for relation-only paths

python src/data_process/data_set.py
```

Path ranking (uses BERT cosine similarity to rank candidate paths):

```bash
python src/data_process/cos_path.py
```

## Core Method

### Model Architecture

1. **BERT Dual-Encoder** (`src/model/model.py`):
   - `bert_hr`: encodes head entity + relation text, producing a head-relation vector
   - `bert_entity`: encodes tail entity text, producing a tail vector
   - Cosine similarity between the two vectors yields the matching score

2. **Path Prompt**: Finds paths from head to tail entity in the KG, converts them to text as supplementary relation information

3. **Neighbor Prompt**: Enriches entity text descriptions with neighborhood information

4. **InfoNCE Contrastive Loss**: Uses additive margin InfoNCE loss to distinguish correct (head, relation, tail) triples from incorrect candidates

## Reproducing Experiments

### Training

Training scripts for all four datasets are provided under `scripts/`. Before running, update the following paths:

- `--pretrained_model`: path to local BERT model (e.g., `/root/autodl-tmp/bert` or `bert-base-uncased`)
- `--device`: GPU device (e.g., `cuda:0`)

```bash
# WN18RR
bash scripts/train_wn18rr.sh

# FB15k237
bash scripts/train_fb15k237.sh

# NELL-995
bash scripts/train_nell.sh

# umls
bash scripts/train_umls.sh
```

Or run directly with Python:

```bash
# Example: WN18RR training
python src/main.py \
    --dataset WN18RR \
    --pretrained_model /path/to/bert-base-uncased \
    --epochs 60 \
    --batch_size 512 \
    --lr 8e-5 \
    --tau 0.03 \
    --pooling mean \
    --use_path_prompt true \
    --use_neighbor_prompt false \
    --experiment_name wn18rr_experiment \
    --do_test \
    --neighbor_weight 0.025 \
    --rerank_n_hop 5 \
    --eval_batch_size 1024 \
    --device cuda:0
```

### Evaluation

After training, evaluate using the saved checkpoint:

```bash
# Update checkpoint_path to point to your trained model
# Models are saved to ./output/{experiment_name}/checkpoints/model_last.pth by default

python src/evaluate.py \
    --checkpoint_path ./output/wn18rr_experiment/checkpoints/model_last.pth \
    --batch_size 1024 \
    --neighbor_weight 0.025 \
    --rerank_n_hop 5 \
    --device cuda:0
```

Evaluation results are saved under `./output/{experiment_name}/`:
- `test_results_model_last.txt`: forward/backward/averaged metric summary
- `forward_details_model_last.json`: forward prediction details
- `backward_details_model_last.json`: backward prediction details

## Output Directory Structure

```

```
